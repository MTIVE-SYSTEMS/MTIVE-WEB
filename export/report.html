PANOPTES / DETECTION REPORT — 2026-09-20

Detection, measured.

Vigil is the object detector at the core of Panoptes — anchor-free, NMS-free-at-export, trained from scratch for this project rather than fine-tuned from an existing backbone. Argus names its successive training runs, v2, v2.5, v3, not a separate model; every figure below is a Panoptes checkpoint at a different point in training. Every number on this page comes from this week's benchmark pass on two real, held-out evaluation sets, run and timed on the project's own hardware.

A hardware constraint that shaped every design choice

Measured directly on the RX 7900 XT: dense 3×3 convolution reaches 80.3 TFLOPS, 98 percent of measured peak. Depthwise 3×3 — the building block of most efficient mobile backbones, MobileNet, EfficientNet, ConvNeXt-style designs — reaches only 0.15 TFLOPS.

Verdict: this inverts the standard "use an efficient mobile backbone" advice. Vigil is built entirely from dense 3×3 convolutions and 1×1 projections, with grouped convolution only at low group counts — a direct, measured consequence of the team's own hardware.

Dual-head design

Vigil trains two prediction heads at once: o2o, one-to-one and NMS-free, the head intended for export; and o2m, a traditional NMS-based fallback. The gap between them is tracked every evaluation, since it decides whether the NMS-free path is ready to ship.

Honest caveat

The o2o head still trails o2m by 0.008 to 0.036 AP on both checkpoints. At epoch 39 of this schedule that reads as too early to judge, not a settled regression — v3's o2o-vs-o2m gap is similar to or smaller than v2's on three of four comparisons.

o2o converges later by construction — one positive assignment per object, versus roughly thirteen for o2m — so it is expected to lag early and close late, not immediately.

02 Detection accuracy

V3 wins. Both sets, both heads.

Two held-out sets, both genuinely unseen by training. COCO val2017 (n=760 of a nominal 960 — 200 pruned for disk budget; small enough that rare classes are noisy). OpenImages val17 (n=3,414, all present — larger, and the more trustworthy evidence here).

Gray bar: v2. Green bar: v3. V3 wins on both eval sets, both heads, consistently — not one cherry-picked number. The OpenImages gap, +0.031 to +0.036 mean AP across 4.5 times more images, is the number to trust more.

Honest caveat

Person AP is dramatically lower on OpenImages, 0.18 to 0.21, than on COCO, 0.39 to 0.42, for both checkpoints. A real domain-difficulty gap — OpenImages' person crowd and scale distribution is harder for this model — not a v2-versus-v3 story. Flagged here, not smoothed over, and not yet investigated.

Verdict

Ship v3 as the new default detector: strictly better mAP on both eval sets, at zero latency or meaningful VRAM cost. Not previously done because v3 was still training when the default was last set — it finished four days before this report and had not been re-evaluated against v2 until this pass.

03 Vigil-Motion — the genuinely separate module

Not a training run. A different model.

A standalone, detector-agnostic movement model. Given consecutive frames, it outputs a per-cell probability heatmap that nudges any detector's confidence — separate code, separate weights, separate training run, cited here from its own dated verification pass rather than re-run for this report.

Honest caveat — the one that matters most

The shipped model is still more appearance-driven than motion-driven: RGB alone reproduces 86 percent of the held-out gap, flow alone only 63 percent. Modality-dropout training meaningfully rebalanced this from the first version's 81/5 split, but did not fully solve it. The heatmap is a more independent second opinion than before — not proven to be a fully independent one.

Composability is proven on a real shared clip: the same heatmap, computed once, boosted both Panoptes' and an unrelated off-the-shelf YOLOv11n's confidence on the same real person by a comparable amount — confirming the fusion mechanism is genuinely detector-agnostic, as designed.

04 Open questions

Not yet answered by this benchmark.

  • Why person-class accuracy differs so sharply between COCO and OpenImages for both checkpoints has not been investigated.
  • Whether the NMS-free (o2o) head's persistent trailing behind o2m is expected to close with more training, or is a structural gap, is unresolved.
  • Vigil-Motion's heatmap remains measurably more appearance-driven than motion-driven, per its own shipped-checkpoint ablation.
